# LULC Classification & Change Detection (Al-Baha Region 2015–2026)

## Overview
An 11-year spatiotemporal analysis evaluating Land Use and Land Cover (LULC) changes in Al-Baha region, Saudi Arabia. The study applies unsupervised classification and spectral indices analysis on satellite imagery to detect urban expansion, vegetation dynamics, and spatial land surface changes.

## Methodology & Workflow
- Satellite Imagery Acquisition & Preprocessing
- Unsupervised Classification using ERDAS IMAGINE
- Spectral Indices Calculation (NDVI for vegetation & MNDWI for water bodies)
- Spatial Change Detection Analysis & Cartographic Mapping in ArcGIS Pro

## Technical Stack & Tools
- ERDAS IMAGINE
- ArcGIS Pro

## Deliverables & Results
- Spatiotemporal Land Cover Maps (2015 vs 2026)
- Spectral Signature & Index Visualizations (NDVI / MNDWI)
- Quantified Land Cover Change Detection Report
